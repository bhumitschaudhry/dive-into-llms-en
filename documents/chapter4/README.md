# LLM Mathematical Reasoning

This project implements code for training large language models (LLMs) to learn mathematical reasoning. The main technique uses Supervised Finetuning (SFT) to teach the model using responses generated by DeepSeek-R1, learning complex mathematical reasoning skills such as reflection and verification.

This experiment is based on the [DeepMath-103K](https://huggingface.co/datasets/zwhe99/DeepMath-103K) dataset and the [Qwen/Qwen2.5-Math-1.5B](https://huggingface.co/Qwen/Qwen2.5-Math-1.5B) model, guiding readers through a complete data distillation workflow on mathematical tasks.

## Experiment Objectives
- Understand data cleaning and preprocessing for mathematical datasets
- Understand basic methods for fine-tuning large models
- Understand basic methods for performing inference with large models
- Understand basic methods for evaluating model mathematical capabilities

## Environment Requirements

- Python 3.8+
- PyTorch
- Transformers
- Datasets
- vllm
- GPU with at least 40GB VRAM

## Experiment Documentation

1. Open Jupyter notebook:
```bash
jupyter notebook sft_math.ipynb
```

2. The notebook contains several main parts:
   - Dataset download and preprocessing
   - Model loading and training
   - Model generation and evaluation

3. Please refer to the notebook for specific operations and instructions.

## Output Files

The training process will generate training checkpoint files, and the generation results will be saved after completion.
